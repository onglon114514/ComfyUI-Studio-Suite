# Prompt Studio 双语对照

## 两类按钮

- **翻译正向 / 翻译反向**：改变上方实际提示词，原文保留在下方对照。
- **A/B（一键翻译所有关键词）、正向对照 / 反向对照**：只生成下方对照，不改写上方提示词。选择“中文对照”可阅读英文提示词；选择“英文对照”可保留中文模型输入并阅读英文释义。

已完成的对照不会重复翻译。对照保存在当前节点的工作流属性中，关闭编辑器再打开仍保留；保存工作流 JSON 后可以随工作流迁移。旧版本已经丢失且未保存的对照不能凭空恢复，需要再点一次对照。

## 本地词典优先

对照先查询本机角色别名索引和 `prompt_studio/storage/local_complete_tags/*.csv`，再用所选离线引擎补齐缺词。“自动”在 HY-MT 可用时优先使用它，不再调用旧 A/B 的在线翻译服务。词典缺失或损坏不应阻止模型补译；模型也未安装时会显示未完成提示。

双语 CSV 使用两列 `英文标签,中文译名`，例如：

```csv
blue_eyes,蓝眼睛
silver_hair,银发
```

支持 UTF-8（可带 BOM）及 GB18030。该接口只返回本次请求的命中项，不把完整词表加载到浏览器。`tag_a,tag_b,count` 的 Danbooru 共现 CSV 是关联统计，不是译名字典。角色索引的安装方法见 [本地翻译与词典说明](LOCAL_TRANSLATION_PLAN_zh-CN.md)。

## 性能与保护

- ComfyUI 队列忙时，翻译和对照按钮禁用；后端仍保留跑图前释放翻译模型的保护。
- 对照串行补译，可以取消；过程中修改文本会停止旧请求结果的写入，不覆盖编辑。
- 关闭窗口仍销毁 iframe，不靠隐藏大型页面来保留对照。
- Prompt Studio 内装饰动画和过渡已禁用，保留静态状态及进度文字。这是减负措施，不代表浏览器原生崩溃已被证明解决。

升级此版本后需要重启一次 ComfyUI（注册词典接口），并刷新 ComfyUI 浏览器页面。用户的 `group_tags` 和自定义词库无需移动或覆盖。
